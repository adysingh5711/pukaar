Install Pukaar in Logos Basecamp

Pukaar is a community issue tracker for a shared site such as a camp, a building or a neighborhood. Members report faults like a broken light or a blocked drain, and a report is only closed when the person who filed it, or two other residents, confirm the fix. Private chat and meetings are in the same app.

What you need

  • Logos Basecamp 0.3.1. Download it first, then open it.
    Download Basecamp 0.3.1
  • A Mac with Apple silicon. The current packages are built for darwin-arm64 only.
  • An internet connection. Messages travel over the Logos Delivery development network.
  • Every person at a site must run a Pukaar build that uses the same network.

Add a package source

Basecamp keeps a list of sources it can install apps from. Add the Pukaar source once. Then Basecamp installs Pukaar and the modules it needs.

  1. Copy the Pukaar source link

    You will paste this link into Basecamp in step 5.

    https://raw.githubusercontent.com/adysingh5711/pukaar/main/public/install/logos-repo.json

  2. Open Basecamp, then Manage Packages

    Start Basecamp. On the Welcome page, choose Manage Packages.

  3. Choose Manage Repositories

    The Package Manager opens. Choose Manage Repositories at the top right of the package list.

  4. Click the Add a repository box

    Settings opens on Package Repositories. Under Add a repository, click the empty box.

  5. Paste the link and choose Add

    Paste the link from step 1, then choose Add.

  6. Check that Pukaar is listed

    Pukaar now shows under Logos Official, switched on (Enabled).

  7. Open Applications

    In the left bar, choose the Applications icon, the first of the three icons at the bottom.

  8. Find Pukaar and click it

    Pukaar has its own group at the bottom of the list, marked INSTALL. If it is not there yet, wait for the list to refresh, or choose Reload.

  9. Choose Install

    A window called Add Application lists the packages Pukaar needs. Choose Install and accept. Basecamp installs Pukaar and the modules it needs. Then do the restart step below.

    Unsigned warning. If Basecamp warns that the package is not signed or not trusted, read the warning before you accept.

Install by hand

Use this if you cannot add a source. Download the files, then install each one from the Package Manager.

  1. Download the five files

    You will install them in this order. Skip any module that Basecamp already has.

    1. delivery_module-0.4.0.lgx (sends your messages)
    2. storage_module-3.0.2.lgx (keeps files)
    3. chat_module-0.3.0.lgx (private chats)
    4. logos-pukaar_core-module-lib.lgx (Pukaar core)
    5. logos-pukaar_ui-module.lgx (the Pukaar screens)

    The first three come from the official Logos module catalog. The last two come from the Pukaar releases page, with a SHA256SUMS file you can use to check them.

  2. Open Basecamp, then Manage Packages

    Start Basecamp. On the Welcome page, choose Manage Packages.

  3. Choose Install Local Package

    In the Package Manager, choose Install Local Package, then pick the first file. Repeat for each file, in the order above. Then do the restart step below.

After you install: restart Basecamp fully

  1. Quit Basecamp completely

    Closing the window is not enough.

  2. Start Basecamp again

    Delivery keeps the network it was first started with, so a full restart is the only way it picks up the right one.

  3. Open Pukaar

    To join a site, paste its site id under Join a site. To start a new site, choose Create a site.

Known limits

  • There is no relay for sites with no internet yet.
  • One Basecamp profile holds one Pukaar identity. You can still join many sites, each with its own site id.
  • The proof anchored on the Logos chain is only as lasting as the test network it uses.
