Install Pukaar in Logos Basecamp

Pukaar is an app for reporting faults in your neighbourhood, such as a broken light or a blocked drain. A report is only closed when the person who filed it, or two other residents, confirm the fix.

Option 1: Add a package source

Basecamp keeps a list of sources it can install apps from. Add the Pukaar source once. Then Basecamp installs Pukaar and the modules it needs.

Loading...
  1. Copy the link above.
  2. Open Basecamp, then open Package Manager.
  3. Choose Add source (it may be called Add repository) and paste the link.
  4. Wait for the list to refresh. Find Pukaar and choose Install.
  5. Basecamp asks to install the modules Pukaar needs. Accept. Then do the restart step below.

If Basecamp warns that the package is not signed or not trusted, read the warning before you accept.

Option 2: Install by hand

Use this if you cannot add a source. Download the files, then in Basecamp open Package Manager and choose Install Local Package for each file. Install them in this order. Skip any module that Basecamp already has.

  1. delivery_module-0.4.0.lgx (sends your messages)
  2. storage_module-3.0.2.lgx (keeps files)
  3. chat_module-0.3.0.lgx (private chats)
  4. logos-pukaar_core-module-lib.lgx (Pukaar core)
  5. logos-pukaar_ui-module.lgx (the Pukaar screens)

The first three come from the official Logos module catalog. The last two come from the Pukaar releases page, with a SHA256SUMS file you can use to check them.

After you install: restart Basecamp fully

Quit Basecamp completely, then start it again. Closing the window is not enough. Delivery keeps the network it was first started with, so a full restart is the only way it picks up the right one.

Then open Pukaar. To join a site, paste its site id under Join a site. To start a new site, choose Create a site.

What you need

  • Logos Basecamp 0.3.1.
  • A Mac with Apple silicon. The current packages are built for darwin-arm64 only.
  • An internet connection. Messages travel over the Logos Delivery development network.
  • Every person at a site must run a Pukaar build that uses the same network.

Known limits

  • This is a pilot. It is not ready for a large public site.
  • There is no relay for sites with no internet yet.
  • One Basecamp profile holds one Pukaar identity. To run two people on one computer, give each its own Basecamp profile.
  • The proof anchored on the Logos chain is only as lasting as the test network it uses.
